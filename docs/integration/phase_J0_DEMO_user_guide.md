# 《电液转向系统联合仿真平台》用户使用说明

面向甲方演示人员。无需编程基础。

---

## 1. 启动

双击项目根目录下的 **`start_steering_demo.bat`**。

- 使用指定的 Python 环境：`E:\ProgramData\condaData\envs_dirs\steering_sim\python.exe`
- **完全离线**，不连接互联网，**不依赖 Amesim**
- 启动失败时会弹出中文窗口说明原因（解释器不对 / 依赖缺失 / 文件不完整）

只做环境自检、不打开界面：

```bat
start_steering_demo.bat --check-only
```

首次打开需要约 30 秒构建机械模型（M1 闭链查表），之后界面即可交互。

---

## 3. 典型演示流程

1. **选择预设工况**：下拉框选择 `J0-01 直行 0° / 0 km/h`。
   左侧所有输入框会自动填入该工况的参数。
2. **查看检查结论**：右侧上方立即显示机械检查、供油检查与范围提示。
3. **运行**：
   - 点 **「预设结果回放（快速，不重新计算）」**——秒级返回，适合演示；
   - 或点 **「运行仿真」**——实时重新积分，约 20~40 秒。
4. **切换结果页**：机械转向结果 / 液压结果 / 控制结果 / 工况与限制。
5. **导出**：`导出时间序列 CSV…` 或 `导出结果报告…`。

依次演示四个预设工况即可覆盖直行、左转、右转、大转角四种状态。

## 4. 输入项说明

| 输入项 | 单位 | 甲方任务书范围 | 已验证动态联调范围 | 默认值 |
|---|---|---|---|---|
| 一桥外侧目标转角 | ° | −30 ~ +30 | **−5 ~ +5** | 0 |
| 车速 | km/h | 0 ~ 80 | **0 ~ 10** | 0 |
| 地面摩擦系数 | — | 0.7 ~ 0.8 | **0.75** | 0.75 |
| 每桥轴荷 | t | 10 ~ 13 | **11.5** | 11.5 |
| 仿真时长 | s | 0.5 ~ 60 | 0.5 ~ 60 | 5.0 |

**界面允许录入甲方任务书给出的完整范围，但不会静默外推。**
超出已验证范围的工况会被标记为"外推"；超出任务书范围的输入会直接被拒绝运行。

> 摩擦系数 0.75 与每桥轴荷 11.5 t 是**工程假设**
> （`ASSUMED_ENGINEERING_PARAMETER`，取自 M1 默认扫描值），不是实车测量值。

## 5. 结果怎么看

### 五个结果页

| 页面 | 内容 |
|---|---|
| **机械转向结果** | 六桥十二轮俯视结构示意（含三桥锁止高亮）；各桥实际角 / 机构可达角 / 理想阿克曼角 |
| **液压结果** | 四通道 A/B 腔压力；液压缸行程与活塞速度；液压力与地面负载；主阀控制输入；A 腔流量 |
| **控制结果** | 行程误差；轮角跟踪误差；PID 输出 |
| **工况与限制** | 附着利用率；轮胎侧偏角；泵供量 vs 高压轨取流与余量；工况参数与模型限制 |

### 三个角度不是一回事

| 名称 | 含义 | 用途 |
|---|---|---|
| **实际角** | 由真实液压缸位移经机构闭链反求 | 唯一的"真值"输出 |
| **机构可达角** | M1 刚体闭链在目标机构坐标上真正能达到的角度 | J0 闭环的跟踪目标 |
| **理想阿克曼角** | 按共同瞬时中心算出的几何理想值 | 只作参照，不代表机构能达到 |

平台从不把三者合成一条曲线。把"实际 − 机构可达"当作跟踪误差，把
"机构可达 − 理想阿克曼"当作机械拓扑的固有偏差——两者相加才是对理想阿克曼的
总偏差。

### 判定颜色

- 绿色 `PASS`：跟踪误差在允许带内且无其他问题；
- 黄色 `CONDITIONAL`：可运行但有需注意之处（例如前通道稳态残差 0.311°）；
- 红色：运行失败或输入不可运行。

## 6. 常见警告的含义

| 标记 | 含义 | 该怎么办 |
|---|---|---|
| `ACKERMANN_GEOMETRY_DEVIATION` | 五、六桥左右轮朝相反方向偏转，且机构可达角与理想阿克曼角偏差较大。这是 M1 闭链在甲方硬点下的真实解，不是程序错误 | 演示时如实说明；不要把机构角当成理想阿克曼结果 |
| `SUPPLY_CAPACITY_NEAR_LIMIT` | 前组供油余量只有泵供量的约 4%，贴近上限 | 属于工程适用范围边界，演示时说明 |
| `SUPPLY_CAPACITY_OUT_OF_RANGE` | 该工况下确实供油不足，腔压力与流量不再代表真实泵能力 | 只能作工程趋势演示，不可标记为验证通过 |
| `EXTRAPOLATION:*` | 输入超出已验证动态联调范围 | 结果属于外推，需明确说明 |
| `GEOMETRY_INFEASIBLE` | 目标转角下 M1 闭链不可达 | 界面拒绝运行，请减小目标转角 |
| `INPUT_OUT_OF_TASK_RANGE:*` | 输入超出甲方任务书范围 | 界面拒绝运行 |

## 7. 「预设结果回放」与「运行仿真」的区别

| | 预设结果回放 | 运行仿真 |
|---|---|---|
| 计算 | 不计算，直接读取缓存 | 实时积分 10 ms 控制 / 0.5 ms 液压 |
| 耗时 | 秒级 | 20~40 秒 |
| 适用范围 | 仅四个预设工况的原始参数 | 任意合法输入 |
| 界面标注 | **预设结果回放**，并显示缓存时间与代码版本 | **重新运行仿真** |
| 输入被改动后 | 提示"与预设不一致，无法回放" | 正常计算 |

回放结果**永远不会**被显示成"刚刚完成的实时仿真"。

---

## 8. 导出文件

- **CSV**：一次运行的全部时间序列（UTF-8 带 BOM，Excel 可直接打开）。
  首列 `time_s`；其余列名如 `channel_front_x_m`、`wheel_axle5_left_actual_deg`。
- **结果报告**：Markdown 文本，含工况、判定、十二轮表、液压表、供油余量、
  控制指标、模型限制与来源标注。

## 10. 故障排查

| 现象 | 原因与处理 |
|---|---|
| 双击 BAT 闪退 | 用 `start_steering_demo.bat --check-only` 查看自检输出 |
| 提示"Python 解释器不正确" | 必须用 `steering_sim` 环境的解释器，不要用系统 Python |
| 提示"运行依赖不完整" | 在 `steering_sim` 环境中补齐 numpy / scipy / matplotlib / pillow |
| 图像中文显示成方框 | 系统缺少中文字体（Microsoft YaHei / SimHei） |
| 运行很慢 | 属正常；演示时用「预设结果回放」 |
