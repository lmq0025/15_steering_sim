## 2. F1：液压缸力与容积的符号一致性

### 2.1 根因

`src/steering_sim/hydraulics_lumped/actuator.py` 中，容积与压力连续性方程是自洽的：

```
V_a = V_a0 - A_a*x        V_b = V_b0 + A_b*x          （chamber_volumes）
dp_a = beta/V_a*(q_a + A_a*v - leak)                   （等价于 dp = (beta/V)(q - Vdot)）
dp_b = beta/V_b*(q_b - A_b*v + leak)
```

即 **x 增大压缩 A 腔、扩张 B 腔**。但力的方向沿用了相反的一组约定：

```
F_hyd = A_a*p_a - A_b*p_b        ← 修复前
```

于是 A 腔受压时产生的不是回复力而是**推力**，液压刚度与阻尼同时取发散符号。

### 2.2 改动

仅改力的方向，容积与压力连续性方程一字未动：

```python
force = actuator.area_b * p_b - actuator.area_a * p_a
```

同时把「让 p_a = p_b = p_rail 成为平衡点」的配套外载符号一并更正
（`hydraulics_lumped/working_point.py`、`j0_coupling/authority.py`），
否则 t = 0 会带上一个 `2*(A_b - A_a)*p_rail` 的净力阶跃。

核对了任务书要求逐项检查的其余项，结论如下（均**未改动**）：

| 项 | 结论 |
|---|---|
| 端口流量正方向 | `physical_a/b` 由工作口换位关系决定，与容积约定无关；见第 3 节 |
| 坐标正方向 | x 增大压缩 A 腔，与容积公式一致 |
| 液压—机械功率平衡 | 由 F1 测试 4 验证：零命令下 `∫F·v dt < 0`，被动吸能 |
| 泄漏流量方向 | `leak = leakage*(p_a - p_b)`，高压腔流向低压腔，符号正确，保留 |
| 机械阻尼 / 摩擦阻力 | 均以 `-c*v`、`-sign(v)*F_f` 阻动，符号正确，保留 |
| 外部负载力 | `positive resists positive x` 约定不变；J0 负载反馈正负号无需调整（第 6 节验证） |
| 初始力平衡 | 改由 `precharged_state()` 求解，见第 5 节 |

**没有把速度或控制命令整体取负来掩盖错误。**

## 3. F2：前桥双向作动能力

### 3.1 根因（三处叠加）

1. `model.py` 对 `dirvalve_6` 特判 `physical_a, physical_b = 0.0, vf_local.q_b`，
   前缸 **A 腔没有任何阀口流量**，只能经泄漏跟随 B 腔。
2. `parameters.py` 中 `channel_front` 的 `valve_work_port_swaps = (False,)`，
   与 IR V3 审计记录相反：
   `phase_L1_R2_macro_mapping_report.md`：「IR V3 显示 dirvalve_2/9/12 的工作口相对
   对应主阀交叉连接；**dirvalve_6 相对 actuator002 的 A/B 工作口也换位**」；
   `audit_parameters.py` 亦记录 dirvalve_6 与 dirvalve_8 的 SUBMODEL 外端口暴露映射
   完全相同（ext0=P、ext1=T、ext2=B、ext3=A）。
3. `parameters.py` 只给 `actuator002` 写入 `leakage = 0.5 L/min @ 100 bar`，
   后三通道为 0。该值无源参数支持，且与三处证据相反：
   `R03B15_AMESim_manual_execution_guide.md:60`「leakage 0 L/min/bar」、
   `R03B1_implementation_report.md:70`「leakage/viscous friction 均为 0」、
   `phase_L1_R3_physics_mapping_report.md:5`「no pressure clamp or artificial leakage」。
   它的实际作用正是给被隔离的 A 腔留一条补油通路，把两腔压力强制拉平，


### 5.2 负载反馈正负号核查

F1 只改液压力的方向，`external_load_forces_n > 0 抵抗正 x` 的约定不变，
因此 J0 的道路负载换算 `F_load = Q_road / (dx/dq)` 方向不变、无需调整。
核查方式：四组 `F_load` 与 `x` 同号（即道路负载起回复作用），
且每个 RK4 stage 的虚功恒等式 `F_load·ẋ ≡ Q_road·q̇` 实测残差 ≤ 2.84e-14 N·m/s。

从最小 P/PI 起步，`kd = 0`（未滤波微分项在 10 ms 采样下不提供有效阻尼相位），
最终取 `kp = 150`、`ki = 60`、`kd = 0`，四通道相同。只做了使误差进入毫米级的必要
调整，**未做最优整定**，也未使用任何人造阻尼。控制方向正确、无持续发散、
命令限幅生效、抗饱和未被触发、零目标稳定保持。

**前通道残差的诊断**（这是 J0-02/J0-03 判 CONDITIONAL 的直接原因）：
`channel_front` 在 5 s 内收敛到 −8.78 mm（目标 −9.88 mm，88.8%），其上叠加一个
幅度约 ±1.6 mm 的低阻尼振荡，最终误差约 1.1 mm。原因有两层：

1. 前端组的作动力已接近负载需求上限——前通道静态力窗口 ±6 208 N，而 M1 工程假设
   负载在 +2° 目标处需要约 6 249 N；
2. 前通道在中立命令附近的液压刚度很弱（`dF/dx = −1.03e3 N/m`，而后通道为
   −1.9e4 … −1.35e5 N/m），位置环主要靠道路负载提供的刚度支撑，因此呈现轻阻尼振荡。

为此做了 5 组增益试验（仅改前通道，2 s→5 s，其余通道不变）：

| (150, 60, 0) ← 采用 | −8.777 | 0.3110 | CONDITIONAL |
| (150, 60, 5) | −8.738 | 0.3090 | CONDITIONAL |
| (150, 60, 15) | −8.730 | 0.3126 | CONDITIONAL |

结论：**该残差不是整定不足**，靠 PID 已无实质改善空间；继续搜索属于任务书第 8 节
明确不要求的最优整定。按第 8 节"不要求第一轮达到最终 10% 精度"，本轮保留
