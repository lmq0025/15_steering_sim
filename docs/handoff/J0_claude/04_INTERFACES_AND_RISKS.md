## 1. 证据等级

- **VERIFIED_CODE**：可从当前正式源码直接确认。
- **CUSTOMER_GEOMETRY**：来自冻结甲方坐标，经 mm→m 转换。
- **ASSUMED**：J0 为打通接口所需但缺少甲方/跨模块证据的工程假设。
- **UNVERIFIED**：尚不可安全使用，必须先补证据或试验。

## 3. 主等效行程与伴随缸

### 前组

```text
x_front[m] = 0.25[m/rad] * q_front[rad]
q_front = x_front/0.25
dx/dq = +0.25 m/rad
```

这是 M1 配置中的占位接口，前缸绝对长度和安装点均为空。它只适合 J0 管线联调，不能用于实车行程、力臂或载荷验收。

### 四至六桥

`CUSTOMER_GEOMETRY` 已给 A/B 两缸的车架端与摆臂端，因此：

```text
x_A(q) = L_A(q)-L_A(0)
x_B(q) = L_B(q)-L_B(0)
J_A = dL_A/dq,  J_B = dL_B/dq
```

建议 J0 首版暂取 `x_hyd=x_A(q)` 为主等效坐标，反解 q 后用同一 q 计算 `x_B`。这个“液压通道对应 A 缸坐标”的选择是 ASSUMED；客户硬点、A/B 长度和伴随关系本身是 CUSTOMER_GEOMETRY。若后续证据表明液压传感器对应 B 缸或双缸合成坐标，只替换 adapter 映射，不修改闭链和液压本构。

严格双缸虚功为 `Q=J_A F_A+J_B F_B`。当前单通道 L1-Fast 没有 `F_A,F_B` 两套状态，所以 J0 只能使用一个明确命名的等效力；不能复制 `F_hyd` 到 A/B 再求和。

## 4. 单位契约

| 量 | 接口单位 | 转换规则 |
|---|---|---|
| 甲方硬点 | mm | `m = mm*1e-3`；只在 input_spec 构建时转换 |
| 液压 x/行程 | m | M1 CSV 的 mm 必须乘 `1e-3` 后进入 J0 |
| 压力 | Pa(g) | `MPa = Pa/1e6` 仅显示；不得把 MPa 数字直接输入 RHS |
| 流量 | m³/s | `L/min = m³/s*60000` 仅显示 |
| 力 | N | 液压 `external_load_forces_n` 和 `hydraulic_force_n` |
| 道路/广义力矩 | N·m | 用行程雅可比换算为 N |
| q、轮角内部 | rad | `rad=deg*pi/180`；外侧目标和报告可用 degree |
| 速度 | m/s、rad/s | 车速输入 km/h 先除 3.6；泵速接口是 rad/s |

禁止在同一个字段混放 mm/m、degree/rad 或 MPa/Pa。输出列名必须携带单位。

## 5. 符号契约

- 整车目标：左转正、右转负；左转一桥右轮是外侧，右转一桥左轮是外侧。
- `q_front/q4/q5/q6`：主摆臂相对零位平均角增量，是内部机构坐标，不是轮角、缸位移或控制命令。不同桥轮角方向由真实几何决定。
- M1 后桥几何行程：`x=L(q)-L(0)`，长度增加为正。前组占位行程与 `q_front` 同号。
- L1-Fast x 增大时 chamber A/1 容积减小、B/2 容积增大；`F_hyd=A_A*pA-A_B*pB` 为正向液压力。
- `external_load_forces_n>0` 在 `dv=(F_hyd-F_load-...)/m` 中抵抗正 x。
- 阀命令正负只表示 SC_1 表的命令方向，**没有证据表明正命令必然产生左转**。四通道须分别做极性测试，在配置中记录 `command_polarity`。

## 6. 力和负载转换

使用虚功，不用任意比例：

```text
x = phi(q), J=dx/dq
qdot = xdot/J
F_load = Q_road/J
Q_hyd = J*F_hyd
F_load*xdot = Q_road*qdot
```

这里 `Q_road` 必须来自当前实际 q 上的轮胎/道路力矩与 `d(delta_wheel)/dq`。当 `J≈0` 时负载换算发散，必须标记映射奇异并停止，不得夹紧成一个看似正常的力。J 的符号必须保留。

M1 当前道路模型：侧向需求按速度平方和曲率计算，按轴荷并满足总力/横摆力矩平衡分配，轮力裁剪到 `mu*Fz`；低速原地阻力和行驶回正力矩用速度权重切换。轮胎侧偏角与机械轮角是不同量。

## 7. 初始化与行程边界风险

- 液压 `initial_state()` 的默认压力 0 Pa 与 L1-Fast 验收正常点不同。J0 应使用预建压工作点，否则结果超出当前验证范围。
- 液压行程边界是各通道中心零位的 `±stroke/2`。M1 行程也是相对零位，但其扫描范围不是液压缸实测机械限位。
- 四通道初始 x 均为 0 m；对应 M1 四个 q=0 和七个相对行程=0。
- 初始不平衡液压力若没有配套外载会驱动缸运动；必须明确初始化平衡策略。

## 8. 不得重复计算的内容

| 内容 | 唯一所有者 | 禁止做法 |
|---|---|---|
| pA/pB/x/v 积分 | L1-Fast | 机械层再次积分 x 或 q |
| q 与轮角几何 | M1 刚性闭链 | 直接把目标角复制为实际轮角 |
| 道路负载 | J0 调用 M1 地面公式一次 | 同时调用 `solve_loaded_case` 柔度角并把 Q 再送液压 |
| A/B 伴随缸行程 | 同一 q 的 CUSTOMER_GEOMETRY | 将 A/B 当两个独立 q |
| 控制离散状态 | PID，10 ms | 每 0.5 ms 隐式重复更新积分器 |
