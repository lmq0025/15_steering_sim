### 4.2 05 页面：全样本循环检查点记录

新增的是可选结果记录，不是另一套寿命方程。桌面寿命计算令现有 D3 Monte Carlo 开启 `record_all_states`，紧凑保存每个循环检查点、全部 N 个样本的20状态，以及样本 ID、终止循环、最后安全检查点、所选模式首次硬越限检查点和删失状态。默认非桌面调用保持原接口行为；新增记录不增加随机数抽取、不调整样本推进顺序或终止规则。

记录维度为“循环检查点 × 样本 × 20模式”，不是1000条路径的毫秒级液压积分。预计记录超过512 MiB时显式拒绝并提示减少路径数或上限，不静默少算。每条路径在首次终止后不再作为正常服役路径延伸，后续未记录位置以缺失标识保存，不当作数值求解 NaN 或补成零。
