# `mechanics_ackermann_redesigned` —— 优化设计机构（PHASE M3）

**标签：`ENGINEERING_REDESIGN_PROPOSAL`**
**该机构为基于甲方硬点与工程假设提出的优化设计方案，尚未通过实车验证。**

本包与 `mechanics_ackermann_v2`（甲方原始结构的 `AS_BUILT_REFERENCE`）**并存**，
互不覆盖。甲方任何原始铰点坐标、杆长与液压缸安装点都没有被修改。

---

## 1. 为什么要重新设计

PHASE M2 已确认（证据见 `docs/mechanics/phase_M2_report.md`）：

| 项目 | 一桥 | 二桥 | 四桥 | **五桥** | **六桥** |
|---|---:|---:|---:|---:|---:|
| 四杆距死点 | 76.3° | 83.3° | 85.2° | **9.69°** | **6.57°** |
| 零位传动比 | −0.887 | −0.766 | −0.693 | **−0.034** | **+0.291** |
| 单侧车轮角可达范围 | ±30° 以上 | ±23° | [−29.5°, +26.6°] | 右轮 **[−0.007°, +13.104°]** | 右轮 **[−0.314°, +7.861°]** |

根因是**甲方确认无误的长边拉杆**（五桥 2.4908 m、六桥 3.3767 m）与转向节摇臂
（0.378 m）在零位几乎平行：四杆处在接近"完全伸展"的构型。其直接后果是五、六桥
单侧车轮角**只能单向偏转且左右相反**，不存在"同桥左右轮同向"的装配构型，因此
这两个桥无法实现阿克曼反相转向。这不是转录错误，也不能靠改坐标"修好"。

---

## 2. 新方案

在不改动甲方任何原始坐标的前提下，增加两样东西：

```
液压缸（甲方机架点/安装点不变）
   │
   ▼
甲方摆臂（甲方枢轴、甲方臂长、新增拉杆拾取点）
   │  新设计拉杆
   ▼
中间摇臂 RELAY（新机架枢轴 + 新输入/输出臂）
   │  新设计边拉杆
   ▼
转向节（甲方主销不变，新增转向臂端点 K）
   │
   └── 转向梯形横拉杆（新）──── 同桥另一侧转向节
```

* **保留**：摆臂枢轴与臂长、液压缸机架点与活塞杆点、转向节主销、轮胎中心、
  轴距轮距——全部为甲方原始值；
* **新增**：中间摇臂枢轴、摇臂输入臂端点、摇臂输出臂端点、转向节转向臂端点，
  以及由这些点自动定长的新拉杆；
* 转向梯形放在**两个转向节之间**（一桥、二桥各一组；四、五、六桥各一组），
  因此"同桥左右轮的阿克曼差动关系"由机构本身产生，不再是 M2 等效模式里
  "左右轮严格同角"的人为假定。

前组（一、二桥）保留甲方的跨桥长拉杆 `P03 ↔ P09` 作为一、二桥之间的耦合，
一桥用"中间摇臂 + 转向梯形"，二桥保留"摆臂—边拉杆—转向节"链并重新设计
转向臂端点。

### 关键设计约束（由数值试验发现，写进综合器作为初值规则）

**转向节转向臂不能正好沿横向（±y）。** 此时梯形横拉杆在零位对"左右轮反向转动"
的一阶灵敏度为零，机构雅可比奇异（条件数 → ∞）。阿克曼梯形的经典做法是让转向臂
大致指向共同瞬时转向中心（近乎纵向），既避开奇异，又让横拉杆长度的二阶项产生
正确的差动。

### 2.3 代表行程：对称双缸的"推程缸"

甲方每桥有 A、B 两只缸。J0 的一个通道只能积分**一个**行程状态，所以必须定义
一只"等效代表缸"。实测表明：**只用 A 缸会在 q ≈ −9° 处到达它自己的运动极限并
使行程折返**（缸杆与摆臂枢轴—缸机架点连线共线），六桥的右转向范围因此被腰斩。
这是"把两只缸当一只缸用"造成的假限制，不是机构本身的限制。

因此代表行程取**对称双缸的推程缸位移**：左转（q ≥ 0）用 A 缸，右转（q < 0）用
B 缸。由镜像关系可证它是**奇函数**

    x(−q) = −stroke_B(−q) = −stroke_A(q)

于是只要 A 缸行程在 q ≥ 0 上单调，代表行程就在整个包络上单调、连续、关于零位
对称（实测奇函数误差 0 μm）。两只缸的**真实几何行程**仍然逐只如实输出
（七个物理缸接口不变），两者不可混用。

**这是工程假设，不是甲方实测**：假定两只缸处于同一液压回路、由同一通道驱动。

## 3. 文件

| 文件 | 内容 |
|---|---|
| `design_parameters.json` | 全部新设计点坐标（零位全局坐标，右侧 `NEG_Y`，左侧镜像）+ 摆臂新拾取点 |
| `config.json` | 机构配置：连续延拓实测的 `q` 可解包络、缸行程包络、地面载荷参数、前缸占位接口 |
| `model.py` | `RedesignedAckermannModel`，接口与 `PhaseM1Model` 同构 |

新设计参数由 `scripts/m3/design_synthesis.py`（SciPy Powell 多起点）综合得到，
目标按任务书第七节优先级排列；包络由 `scripts/m3/finalize_redesign_config.py`
连续延拓实测得到，逐门限（残差 ≤1e-9 m、相邻步角增量 ≤3°、条件数 ≤1e8）。

## 4. 结果来源的区分

| 记号 | 含义 |
|---|---|
| `CUSTOMER_LINKAGE_GEOMETRY` | 甲方原始硬点与原始杆件拓扑 |
| `AS_BUILT_REFERENCE` | 用原始拓扑跑出来的结果（对照用） |
| `ENGINEERING_REDESIGN_PROPOSAL` | 本包的新设计机构结果 |
| 液压驱动实际角 | J0 闭环中由**真实液压缸位移**经新机构反求得到的角 |

本包输出的任何角度都**不得**被表述为"原车已验证的机械结构结果"。
