## 2. 工程液压模型（`ENGINEERING_HYDRAULIC_V1`）

经典**阀控对称双腔缸**，四通道；状态向量为每通道 `(pA, pB, x, v, 阀芯)` 加两条共用供油轨 `ps`，共 **22 个状态**（其中 16 个是任务书要求的基本动态状态）。

计算链条与任务书第三节逐字对应：

```
控制命令 u → 阀芯一阶响应 → 阀口流量 Q(pA,pB,ps,u)
        → 双腔压力变化 dpA/dt, dpB/dt → 缸推力 F = pA·Aa − pB·Ab
        → 活塞加速度/速度/位移 (v, x) → 机械映射 → 十二轮实际转角
```

要点：

* **节流口用压差正则化**：`Q = Cd·A·√(2/ρ)·Δp / √(√(Δp²+ε²))`，
  `ε = 0.1 MPa`。Δp 大时退化为标准薄壁孔口，Δp→0 时线性、导数有界 ——
  否则中位附近 `√` 的无穷导数会让 RK4 失稳。
* **对称双出杆缸**（`Aa = Ab`）：转向作动必须左右力与速度对称，这样命令
  极性与运动方向唯一，不需要任何方向补偿。
* **共用供油轨**：定量泵 + 溢流阀 + 蓄能器容积。需求流量超过泵能力时供压
  **真实下跌**，不是无限流量；两条轨分别核算（前组、后三组）。
* **行程限位是真实缓冲**（刚度 = 15× 液压刚度），不做静默裁剪。
* **缸中位带偏置**：机构行程区间本身不对称（甲方缸几何决定），缸全行程与
  机构单调包络端点重合，避免出现「表里查不到、缸还能走」的空档。

## 9. 结论

**做到的**：

* 一套正式工程液压模型，四通道真实闭环；**+30° 不再只转 1°** ——
  一桥外侧轮 ±30° 全部跟踪到 0.001° 以内；
* 正常低速代表工况的十二轮实际角相对机构理论角最大误差 **< 0.002°**，远优于 0.5° 目标；18/18 个工况饱和比例为 0，无持续振荡；
* 61 个目标角的机构模型方向、连续性、镜像、三桥锁零全部通过；
* 3111 工况全部算出且四通道能力全网格不缺；
* 高速大角度工况能算出、能标记风险，不崩溃、不假报成功；
* 界面把「计算完成 / 跟踪达标 / 轨迹物理可行」三件事分开呈现。

**如实保留的限制**：

* 机构对理想阿克曼角的偏差（后三桥最大 RMS 1.8255°）是齿条—梯形拓扑的固有属性，
  液压闭环不负责消除，也不应该被算进跟踪误差；
* 目标轨迹超过轮胎附着时（例如 80 km/h + 30°）车辆在物理上无法沿该路径
  行驶，软件照常完成计算并标记 `VEHICLE_DYNAMIC_INFEASIBLE`；
* 多段连续指令工况的稳态判定受「末段采样窗」定义限制，已在 §6.1 说明；
* 所有液压参数均为工程选型值，未经过甲方实测验证。
