## 2. 机械传动原理

```
液压缸（甲方机架点/杆端安装点不变的几何接口）
   │
   ▼
甲方摆臂（甲方枢轴、甲方臂长；新增拉杆拾取点）
   │  驱动连杆
   ▼
齿条 RACK（新设计，沿 y 平动；每桥一根）
   │  两根边拉杆
   ▼
左右转向节（甲方主销/车轮中心不动）
```

**阿克曼差动由转向梯形本身产生**：左右转向臂的方向取指向该桥共同瞬时转向
中心，齿条平动时左右转向节自然转过不同角度（内侧轮多转）。不是显示层做差，
也不是把目标角复制过去。

**每个机构组都是闭式可解的**（没有最小二乘、没有装配分支搜索）：给定摆臂角，
齿条位移由驱动连杆的一元二次方程给出，转向节角由边拉杆的一元三角方程给出。
因此快、连续、可逆，也不会出现 M3 那种目标角 21°→22° 车轮跳几十度的情况。

设计尺寸（转向臂长度、齿条后移量、边拉杆长度、摆臂拾取半径）逐组由一个小网格
（192 组标量尺寸）选出，判据是工作区间内最小传动角余量最大。这不是机械结构搜索。

## 5. 已修复的两个确认问题

### 5.1 PID 饱和统计（已修复）

旧 `runner.py` 把**限幅后**的 `raw_pid` 再与 `command_limit` 比较，因此永远得到
0% 饱和 —— 与 CSV 里大量阀命令已经贴到 ±1 的事实直接矛盾。
现在 `PIDController` 通过 `PIDDiagnostics` 分开给出未限幅请求、限幅后命令、
逐通道是否贴限幅、积分抗饱和是否触发四项。

实测（+30° / 5 km/h）：

| 通道 | 阀命令贴限幅采样占比 | 未限幅请求峰值 |
|---|---:|---:|
| channel_front | 98.5% | +21.33 |
| channel_rear_1 | 95.5% | +2.67 |
| channel_rear_2 | 97.5% | +6.30 |
| channel_rear_3 | 98.5% | +19.01 |

整体控制饱和比例 0.9751。
这与任务书指出的前桥约 98.5% 位于限幅一致 —— 统计已经正确，不再报虚假的 0%。

### 5.2 道路负载改用实际曲率（已修复）

旧实现直接把**目标曲率**当作车辆已经实现的运动。现在新增
`actual_curvature_1pm()`：由**当前实际车轮转角**的 12 条纯滚动方向线最小二乘求交
得到共同瞬时转向中心，再取曲率。目标曲率只用于工况要求与附着可行性评价，两者在
结果里分别记录（`curvature_target_1pm` / `curvature_actual_1pm`）。

另外，`ADHESION_INFEASIBLE` 与 `OUTSIDE_LINEAR_TIRE_RANGE` **不再中断积分**：
附着不足是物理风险，照常完成数值积分并记录需求力、可提供力与风险标志；
只有负载换算奇异这类真正的数值问题才停止求解。

## 9. 结论

**做到的**：一套正式工程机械模型，61 个目标角方向正确、连续、镜像、三桥锁零、
一桥外轮精确跟随、行程单调可逆；3111 工况全部算出；PID 饱和统计与道路负载曲率
两个确认缺陷已修复；高速大转角能算出并标记可行性。

**没做到的**：动态跟踪仍然不达标，根因已定位并量化 —— **现有执行器出力不足**
（需求 5.6~14.6 kN，力窗口 +6045/−10694 N）。本轮给出了选型建议，但把新液压
参数真正落进 L1-Fast 并重新整定控制，属于需要整体复算的下一步工作，
不在本轮授权完成的范围内。

全仓测试（本阶段）：541 passed。
