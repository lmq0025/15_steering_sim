    10: /* *******************************************************************************
    11: TITLE : HA001
    12: 
    13: ------------------------------------------------------------------------------
    14: DESCRIPTION :
    15: 
    16:    HA001 is a dynamic submodel of a hydraulic accumulator. The
    17:    accumulator gas is assumed to obey a polytropic gas law of the form
    18: 
    19:       gamma
    20:    P V     = polyconstant
    21: 
    22:    where the constant is defined by the initial state of the accumulator
    23:    (depending on the #gas pressure).
    24:    This initial state (actually the gas volume) is whether computed with
    25:    an isothermal law:
    26: 
    27:    P V = constant1
    28: 
    29:    or with an adiabatic law depending on a supplied parameter (0 or 1)
    30: 
    31:        gamma
    32:    P V      = constant1
    33: 
    34:    this constant is given by the gas precharge pressure and the accumulator
    35:    volume.
    36: 
    37:    The gas pressure is assumed to be the same as of the hydraulic fluid
    38:    in the accumulator when the unit is not fully charged or
    39:    discharged.
    40: 
    41:    When it is fully discharged, the hydraulic pressure is
    42:    computed using the equation for a compressible volume of fluid with
    43:    an assumed volume of 1/1000 of the accumulator volume.
    44: 
    45:    When the gas volume becomes 1/1000 of the accumulator volume, the
    46:    accumulator is assumed to be fully charged. This prevents problems
    47:    that would occur if the gas volume tended to zero.
    48: 
    49: ------------------------------------------------------------------------------
    50: USAGE :
    51: 
    52:    There is no orifice law at the inlet which gives HA001 different
    53:    port input and output requirements to HA000.  HA001 gives pressure
    54:    in bar as an output and requires flow rate in L/min as an
    55:    input. This is the opposite of HA000.
    56: 
    57: ------------------------------------------------------------------------------
    58: PARAMETER SETTINGS :
    59: 
    60:    If you require a stabilizing run, there should be thermal equilibrium.
    61:    Hence it is better to set the polytropic index to 1 before performing
    62:    the stabilizing run. If you want to use these values as starting values
    63:    for a transient run, reset the polytropic index to your chosen value
    64:    and use the 'Run with old final values' facility.
    65: 
    66:    The index of hydraulic fluid parameter refers to a fluid type
    67:    defined by an icon put on the sketch.
    68:
