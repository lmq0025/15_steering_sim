    10: /* *******************************************************************************
    11: TITLE : HJ021
    12: ------------------------------------------------------------------------------
    13: DESCRIPTION :
    14:    A double hydraulic chamber, double rod jack, actuator or cylinder
    15:    with a fixed body.
    16: ------------------------------------------------------------------------------
    17: USAGE :
    18:    The submodel includes pressure dynamics in the volumes either side
    19:    of the piston, viscous friction, and leakage past the piston.
    20:  
    21:    If you intend to attach a mass to the jack, it is better to use
    22:    HJ001 rather than HJ021 because HJ001 uses a simpler treatment of
    23:    the actuator endstops. HJ021 uses an endstop model based on a
    24:    spring and damper rate whereas HJ001 uses a completely inelastic
    25:    collision. There are fewer parameters to set with HJ001.
    26: ------------------------------------------------------------------------------
    27: PARAMETER SETTINGS :
    28:    The dead volumes prevent the hydraulic volume becoming zero at the
    29:    ends of the stroke. If in doubt, set these volumes to zero and the
    30:    submodel will reset them to 1/1000 the maximum hydraulic volume.
    31:  
    32:    The user may set a spring and damper rate for the contact at the
    33:    ends of the stroke and also a deformation at which the endstop
    34:    damping is fully effective. FOR MOST SITUATIONS THE DEFAULT
    35:    SETTINGS FOR THESE QUANTITIES ARE SATISFACTORY. If you do need to
    36:    change the values, follow the following advice.
    37:  
    38:    If the spring and damper rate values are numerically of roughly the
    39:    same magnitude, there will probably be no bounce when the end stop
    40:    is reached. This is normally a desirable situation. A lower damping
    41:    rate may result in a bounce and if it is very much lower, there may
    42:    a lot of bouncing. In extreme cases the simulation may stop because
    43:    there are too many discontinuities.
    44:  
    45:    Actuators are normally designed to provide controlled decceleration
    46:    at the extreme positions. The deccelerating force increases
    47:    steadily with actuator position. To allow for this, an endstop
    48:    deformation at which the damping rate is fully effective is
    49:    used. This ensures that corresponding damping force is a continuous
    50:    function of actuator position.
    51:  
    52:    If the spring rate is set too high, the simulation run may be very
    53:    slow.
    54:  
    55:    The index of hydraulic fluid parameter refers to a fluid type
    56:    defined by an icon put on the sketch.
    57:

    59: DATE OF CREATION/AUTHOR : 11/02/97 C.W.Richards.
