    10: /* *******************************************************************************
    11: TITLE : HJ020
    12: ------------------------------------------------------------------------------
    13: DESCRIPTION :
    14:    A double hydraulic chamber, single rod jack, actuator or cylinder
    15:    with a fixed body.
    16:  
    17:    The 2 flow ports require flow rate as an input and supply
    18:    pressure as an output.
    19: ------------------------------------------------------------------------------
    20: USAGE :
    21:    The submodel includes pressure dynamics in the volumes either side
    22:    of the piston, viscous friction, and leakage past the piston.
    23:  
    24:    If you intend to attach a mass to the jack, it is better to use
    25:    HJ000 rather than HJ020 because HJ000 uses a simpler treatment of
    26:    the actuator endstops. HJ020 uses an endstop model based on a
    27:    spring and damper rate whereas HJ000 uses a completely inelastic
    28:    collision. There are fewer parameters to set with HJ000.
    29: ------------------------------------------------------------------------------
    30: PARAMETER SETTINGS :
    31:    The dead volumes prevent the hydraulic volume becoming zero at the
    32:    ends of the stroke. If in doubt, set these volumes to zero and the
    33:    submodel will reset them to 1/1000 the maximum hydraulic volume.
    34:    The user may set a spring and damper rate for the contact at the
    35:    ends of the stroke and also a deformation at which the spring rate
    36:    is fully effective. FOR MOST SITUATIONS THE DEFAULT SETTINGS FOR
    37:    THESE QUANTITIES ARE SATISFACTORY. If you do need to change the
    38:    values, follow the following advice.
    39:  
    40:    If the spring and damper rate values are numerically of roughly the
    41:    same magnitude, there will probably be no bounce when the end stop
    42:    is reached. This is normally a desirable situation. A lower damping
    43:    rate may result in a bounce and if it is very much lower, there may
    44:    a lot of bouncing. In extreme cases the simulation may stop because
    45:    there are too many discontinuities.
    46:  
    47:    Actuators are normally designed to provide controlled decceleration
    48:    at the extreme positions. To allow for this, an endstop deformation
    49:    at which the spring rate is fully effective is used. This allows
    50:    adjustment of the decceration distance in the extreme postions.  If
    51:    the spring rate is set too high, the simulation run may be very
    52:    slow.
    53:  
    54:    The index of hydraulic fluid parameter refers to a fluid type
    55:    defined by an icon put on the sketch.
    56: ------------------------------------------------------------------------------
    57: DATE OF CREATION/AUTHOR : 11/02/97 C.W.Richards.
    58: ------------------------------------------------------------------------------

   563:       powCchamber2 = (*p2 + patm) * inflow2 * q0top_(p2);
   564:       powSpatm = patm * (c[0]-c[1])*(*v) ;
   565:       /* <<<<<<<<<<<<End of Energy Common Statements. */

   583:          *denergySpatm    = powSpatm;
   584:       }
   585:       if (actRleak != NULL)

   588:          /* <<<<<<<<<<<<End of Optional Activity Computation Statements. */
   589:          *dactRleak       = fabs(powRleak);

   594:          *dactSpatm       = fabs(powSpatm);
   595:       }
