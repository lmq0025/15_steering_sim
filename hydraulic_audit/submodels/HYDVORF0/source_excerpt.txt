    13: ------------------------------------------------------------------------------
    14: DESCRIPTION :
    15:  
    16:    HYDVORF0 is a submodel of a symmetric variable orifice. It can have laminar
    17:    or turbulent characteristics and the switch is made at a user supplied
    18:    critical flow number.
    19:  
    20:    There are 5 modes of operation:
    21:  
    22:    i) the user supplies a flow rate in L/min and corresponding
    23:    pressure drop in bar;
    24:  
    25:    ii) the user supplies a equivalent orifice diameter and maximum
    26:    flow coefficient (cq).
    27:  
    28:    iii) the user supplies a geometry and minimum pressure drop coefficient (zeta)
    29:  
    30:    iv) the user supplies a Cv
    31:  
    32:    v) the user supplies a Kv
    33:  
    34:    In all cases the user must also supply the critical flow number at
    35:    which the flow characteristics change from laminar to turbulent.
    36:  
    37: ------------------------------------------------------------------------------
    38: USAGE :
    39:  
    40: ------------------------------------------------------------------------------
    41: PARAMETER SETTINGS :
    42:  
    43:    In most cases the critical flow number (dimensionless) can be left
    44:    at the default value of 1000. However, for an orifice with complex
    45:    (rough) geometry the critical flow number can be as low as 50
    46:    whereas for a very smooth geometry it can be as high as 50000.
    47:  
    48:    The index of hydraulic fluid parameter refers to a fluid type
