    10: /* *******************************************************************************
    11: TITLE : HJ0022
    12: ------------------------------------------------------------------------------
    13: DESCRIPTION :
    14:    A double hydraulic chamber, single rod jack, actuator or cylinder
    15:    with spring assistance at the rod end and a fixed body.
    16: ------------------------------------------------------------------------------
    17: USAGE :
    18:    The submodel includes pressure dynamics in the volumes either side
    19:    of the piston, viscous friction, and leakage past the piston.
    20:  
    21:    If you intend to attach a mass to the jack, it is better to use
    22:    HJ002 rather than HJ0022 because HJ002 uses a simpler treatment of
    23:    the actuator end stops. HJ0022 uses an end stop model based on a
    24:    spring and damper rate whereas HJ002 uses a completely inelastic
    25:    collision. There are fewer parameters to set with HJ002.
    26: ------------------------------------------------------------------------------
    27: PARAMETER SETTINGS :
    28:    The dead volumes prevent the hydraulic volume becoming zero at the
    29:    ends of the stroke. If in doubt, set these volumes to zero and the
    30:    submodel will reset them to 1/1000 the maximum hydraulic volume.
    31:  
    32:    The user may set a spring and damper rate for the contact at the
    33:    ends of the stroke and also a deformation at which the end stop
    34:    damping is fully effective. FOR MOST SITUATIONS THE DEFAULT
    35:    SETTINGS FOR THESE QUANTITIES ARE SATISFACTORY. If you do need to
    36:    change the values, follow the following advice.
    37:  
    38:    If the end stop spring and damper rate values are numerically of
    39:    roughly the same magnitude, there will probably be no bounce when
    40:    the end stop is reached. This is normally a desirable situation. A
    41:    lower damping rate may result in a bounce and if it is very much
    42:    lower, there may a lot of bouncing. In extreme cases the simulation
    43:    may stop because there are too many discontinuities.
    44:  
    45:    Actuators are normally designed to provide controlled deceleration
    46:    at the extreme positions. The decelerating force increases steadily
    47:    with actuator position. To allow for this, an end stop deformation
    48:    at which the damping rate is fully effective is used. This ensures
    49:    that corresponding damping force is a continuous function of
    50:    actuator position.
    51:  
    52:    If the end stop spring rate is set too high, the simulation run may
    53:    be very slow.
    54:  
    55:    The index of hydraulic fluid parameter refers to a fluid type
    56:    defined by an icon put on the sketch.
    57: ------------------------------------------------------------------------------
    58: DATE OF CREATION/AUTHOR : 11/02/97 C.W.Richards.
    59: ------------------------------------------------------------------------------

   548:          powCspring -= k * (*xact - stroke) * (*v);

   551:       powCchamber1 = (*p1 + patm) * inflow1 * q0top_(p1);
   552:       powCchamber2 = (*p2 + patm) * inflow2 * q0top_(p2);
   553:       powSpatm = patm * (c[0]-c[1]) * (*v);
   554:       /* <<<<<<<<<<<<End of Energy Common Statements. */

   569:          *denergyCchamber2 = powCchamber2;
   570:          *denergyRfrict   = powRfrict;

   572:          *denergySpatm    = powSpatm;
   573:       }
   574:       if (actRleak != NULL)
   575:       {
   576:          /* >>>>>>>>>>>>Optional Activity Computation Statements. */
   577:          /* <<<<<<<<<<<<End of Optional Activity Computation Statements. */
   578:          *dactRleak       = fabs(powRleak);
   579:          *dactCchamber1   = fabs(powCchamber1);
   580:          *dactCchamber2   = fabs(powCchamber2);
   581:          *dactRfrict      = fabs(powRfrict);
   582:          *dactCspring     = fabs(powCspring);
   583:          *dactSpatm       = fabs(powSpatm);
   584:       }
   585:    }
