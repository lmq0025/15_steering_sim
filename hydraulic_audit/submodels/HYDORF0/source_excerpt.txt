    11: TITLE : HYDORF0
    12: ------------------------------------------------------------------------------
    13: DESCRIPTION :
    14:  
    15:    HYDORF0 is a submodel of a symmetric orifice. It can have laminar
    16:    or turbulent characteristics and the switch is made at a user supplied
    17:    critical flow number.
    18:  
    19:    There are 5 modes of operation:
    20:  
    21:    i) the user supplies a flow rate in L/min and corresponding
    22:    pressure drop in bar;
    23:  
    24:    ii) the user supplies a equivalent orifice diameter and maximum
    25:    flow coefficient (cq).
    26:  
    27:    iii) the user supplies a geometry and minimum pressure drop coefficient (zeta)
    28:  
    29:    iv) the user supplies a Cv
    30:  
    31:    v) the user supplies a Kv
    32:  
    33:    In all cases the user must also supply the critical flow number at
    34:    which the flow characteristics change from laminar to turbulent.
    35:  
    36: ------------------------------------------------------------------------------
    37: USAGE :
    38: ------------------------------------------------------------------------------
    39: PARAMETER SETTINGS :
    40:  
    41:    In most cases the critical flow number (dimensionless) can be left
    42:    at the default value of 1000. However, for an orifice with complex
    43:    (rough) geometry the critical flow number can be as low as 50
    44:    whereas for a very smooth geometry it can be as high as 50000.
    45:  
    46:    The index of hydraulic fluid parameter refers to a fluid type
    47:    defined by an icon put on the sketch.
