# Examples

`run_mechanical_dynamics_demo.py` is a 10-state integration check using only the
guarded `SYNTHETIC_TEST_ONLY` mass set. Its output is not a customer-vehicle
prediction. Use the verified environment command in `docs/ENVIRONMENT.md`.

`run_mechanical_io_demo.py` demonstrates the current formal position-to-angle
route with BASELINE/SYNTHETIC inputs only and produces a PNG plus CSV. It is not
a calibrated customer-vehicle result.
